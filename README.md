A 1024 × 1024 newspaper front page image summing up the world news of **Tuesday 17 November 2026**.

The page covers **40 stories from seven regions** — Europe, the Middle East, Asia, Africa, the Americas, Latin America, and Climate & Science — laid out in the style of a broadsheet front page: masthead, lead story, by-the-numbers panel, and a three-column brief section with region-coloured tags.

## Run

```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The script validates that `entry.png` is a PNG or JPEG file and is at most 1 048 576 bytes, then copies it to the output directory and prints the path it wrote.
